# Подробная пошаговая инструкция: Запуск GeekNook на Тильде с платежами и CRM

Этот гайд написан максимально просто и понятно — шаг за шагом, клик за кликом.

---

## 📌 В чем суть (объясняем на пальцах)

Ваш сайт GeekNook — это сложное высокотехнологичное приложение (с Three.js 3D-графикой, симулятором нагрузок на Canvas, фоновым видео и анимациями). Файлы сайта весят больше 5 мегабайт.

В Тильде есть ограничение: внутрь одного блока `T123` можно вставить максимум 20 килобайт текста. Целиком засунуть в один блок Тильды весь сайт физически невозможно.

**Как мы это решаем:**
1. **Шаг 1:** Файлы вашего сайта (папки `css`, `js`, `images` и `index.html`) выкладываются в интернет в один клик (бесплатно на Netlify, Vercel или GitHub Pages, либо на ваш хостинг). Вы получаете персональную ссылку на ваш сайт.
2. **Шаг 2:** На странице в Тильде мы ставим нативную корзину Тильды (**блок `ST100`**) и легкий загрузчик (**блок `T123`**), куда вставляем эту ссылку.
3. **Результат:** Человек заходит на ваш сайт на Тильде, видит 100% оригинальный красивый сайт GeekNook, а когда нажимает любую кнопку «Купить» или собирает подставку в 3D — открывается корзина Тильды с приемом карт (ЮKassa, Т-Банк, Сбер, СБП), расчетом доставки СДЭК и записью клиента в вашу Tilda CRM.

   `c:\Users\serge\OneDrive\Desktop\programming shit\geeknook\geeknook\`
3. **Перетащите папку `geeknook` мышкой** в круглое поле на сайте Netlify прямо в браузере.
4. Подождите 10 секунд, пока файлы загрузятся.
5. Netlify выдаст вам готовую зеленую ссылку вида:
   `https://wonderful-cupcake-123456.netlify.app/`
   *(В настройках Netlify можно бесплатно переименовать её в `geeknook-app.netlify.app`)*.
6. **Скопируйте эту ссылку!** Она понадобится в Части 2.

### Способ 2 (Через GitHub Pages — если вы пользуетесь Git)
1. Откройте терминал PowerShell в папке проекта:
   ```powershell
   cd "c:\Users\serge\OneDrive\Desktop\programming shit\geeknook\geeknook"
   git init
   git add .
   git commit -m "Init GeekNook full site"
   ```
2. Создайте публичный репозиторий на [GitHub](https://github.com/new) (например, `geeknook-web`).
3. Отправьте код:
   ```powershell
   git remote add origin https://github.com/ВАШ_ЛОГИН/geeknook-web.git
   git branch -M main
   git push -u origin main
   ```
4. В репозитории на GitHub перейдите в **Settings** (Настройки) → слева вкладка **Pages** → в пункте **Branch** выберите `main` и нажмите **Save**.
5. Через 1 минуту вы получите ссылку: `https://ВАШ_ЛОГИН.github.io/geeknook-web/`.

## 🛠 ЧАСТЬ 2. Настройка страницы в Тильде (по шагам)

Теперь переходим в ваш личный кабинет на **tilda.cc**.

### Шаг 2.1. Создаем чистую страницу
1. В вашем проекте на Тильде нажмите большую оранжевую кнопку **«Создать новую страницу»**.
2. Выберите **«Пустая страница»**.
3. В верхней панели нажмите на белую кнопку **«Настройки»** (иконка шестеренки):
   * Во вкладке **«Главное»**:
     * Заголовок: `GEEK NOOK — Инженерная точность на твоём столе`
     * Описание: `Премиальные модульные подставки под мониторы Focus Station из натурального дерева, стали и фетра.`
     * Адрес страницы (URL): оставьте пустым (чтобы это была главная страница) или укажите `index`.
   * Перейдите во вкладку **«Дополнительно»**:
     * Найдите пункт **«Шапка и подвал»** → выберите **«Не использовать в этой странице»** (это важно, чтобы стандартные шапки Тильды не мешали вашему сайту).
   * Нажмите синюю кнопку **«Сохранить изменения»** внизу.

---

### Шаг 2.2. Добавляем блок корзины Тильды (`ST100`)
Корзина нужна, чтобы покупатель мог оформить заказ, выбрать доставку СДЭК и оплатить:
1. На пустой странице нажмите на плюс или кнопку **«Библиотека блоков»** (в левой панели).
2. В списке разделов выберите **«Магазин»**.
3. Найдите блок **«ST100. Корзина с формой заказа»** и кликните по нему.
4. Наведите на добавленный блок корзины и нажмите кнопку **«Контент»** (в левом верхнем углу блока):
   * В разделе **«Поля для ввода»** включите галочки:
     * `Имя`
     * `Телефон` (поставьте галочку «Обязательно для заполнения»)
     * `Email`
     * `Адрес доставки` (или оставьте для СДЭК)
   * В разделе **«Текст кнопки отправки»** напишите: `Оформить заказ`.
   * Нажмите **«Сохранить и закрыть»**.

---

### Шаг 2.3. Добавляем блок загрузчика (`T123`)
1. Снова нажмите на плюс под блоком корзины, чтобы добавить следующий блок.
2. В левом меню блоков выберите раздел **«Другое»**.
3. Выберите блок **«T123. HTML-код»**.
4. Наведите на него и нажмите кнопку **«Контент»**.
5. Откроется окно с текстовым полем для ввода HTML-кода.
6. Откройте на компьютере файл [tilda-bundle/tilda-loader.html](file:///c:/Users/serge/OneDrive/Desktop/programming%20shit/geeknook/geeknook/tilda-bundle/tilda-loader.html), скопируйте его содержимое и вставьте в окно Тильды.
7. **ВНИМАНИЕ — ГЛАВНАЯ СТРОЧКА:**
   Найдите в начале скрипта строчку №43:
   ```javascript
   const BASE_URL = window.GEEKNOOK_CDN_URL || '';
   ```
   И вставьте туда ссылку, которую вы получили в **ЧАСТИ 1** (со слэшем `/` на конце!).
   
   *Пример для Netlify:*
   ```javascript
   const BASE_URL = 'https://geeknook-app.netlify.app/';
   ```
   *Пример для GitHub Pages:*
   ```javascript
   const BASE_URL = 'https://yourname.github.io/geeknook-web/';
   ```
8. Нажмите кнопку **«Сохранить и закрыть»**.

---

### Шаг 2.4. Публикуем страницу
В правом верхнем углу Тильды нажмите синюю кнопку **«Опубликовать»**.
Тильда сгенерирует ссылку (например, `https://project12345.tilda.ws`). Перейдите по ней!

## 💳 ЧАСТЬ 3. Подключение оплаты, СДЭК и Telegram (в панели Тильды)

Это делается один раз в настройках самого проекта на Тильде:

### 1. Подключение онлайн-оплаты (ЮKassa / Т-Банк / Сбер / СБП)
1. Вверху нажмите **«Настройки сайта»** (главные настройки проекта, а не отдельной страницы).
2. В левом меню перейдите в пункт **«Платежные системы»**.
3. Нажмите кнопку нужного вам банка:
   * **Т-Банк (Тинькофф Оплата):** введите Terminal Key и Пароль из личного кабинета банка.
   * **ЮKassa:** введите shopId и Секретный ключ (поддерживает банковские карты, СБП, SberPay, Мир).
   * **Долями:** подключение оплаты в 4 платежа без комиссий.
4. Поставьте галочку «Тестовый режим», если хотите проверить оплату тестовой картой.
5. Нажмите **«Сохранить»**.

---

### 2. Подключение доставки СДЭК
1. В **«Настройках сайта»** перейдите в пункт **«Формы»**.
2. Прокрутите вниз до раздела **«Службы доставки»** → выберите **«СДЭК»**.
3. Введите логин и пароль от API СДЭК (из личного кабинета СДЭК для интеграций).
4. Укажите город отправки (например, `Москва`).
5. Теперь в корзине при оформлении заказа покупатель сможет выбрать пункт выдачи на интерактивной карте СДЭК, а стоимость доставки автоматически прибавится к сумме заказа!

---

### 3. Моментальные уведомления в Telegram
Чтобы не пропускать ни одной заявки:
1. В **«Настройках сайта»** перейдите в раздел **«Формы»** → выберите **«Telegram»**.
2. Откройте в Telegram бота **`@TildaFormsBot`**, нажмите `/start` и отправьте ему секретный код, который покажет Тильда.
3. Бот привяжется к вашему аккаунту.
4. Теперь при каждой оплате или заполнении формы в ваш Telegram мгновенно прилетает карточка:
   * Имя клиента, телефон, адрес доставки;
   * Выбранная модель (например: *Focus Station 116 см, Американский орех, гравировка CYBER // 2026*);
   * Сумма заказа и статус оплаты.
