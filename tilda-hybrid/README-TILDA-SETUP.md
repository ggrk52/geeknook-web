# Руководство по развертыванию гибридной версии GEEK NOOK на Тильде

Это подробная инструкция по сборке гибридного сайта **GEEK NOOK** на платформе **Tilda**. 

Гибридная схема объединяет лучшее из двух миров:
1. **Тильда** берет на себя маркетинг, SEO, стандартный каталог, прием платежей (ЮKassa / Т-Банк / Сбер), СДЭК и CRM.
2. **Инженерный стек GEEK NOOK** (3D-конфигуратор Focus Station, сопромат-симулятор FEA Lab, калькулятор эргономики, палитра команд `⌘K`) работает через автономные виджеты в блоках `T123`.

---

## 📁 Структура подготовленных файлов в папке `tilda-hybrid/`

* **`tilda-catalog-import.csv`** — Готовая база товаров (18 позиций) в кодировке UTF-8 с артикулами, ценами, описаниями, спецификациями и вариациями.
* **`export-tilda-catalog.js`** — Скрипт-генератор CSV из `js/products-data.js` (можно запускать при изменении цен или добавлении товаров).
* **`widget-3d-configurator.html`** — Автономный виджет 3D-конфигуратора Focus Station с мостом в корзину Тильды (`tcart`).
* **`widget-fea-lab.html`** — Автономный виджет FEA Stress Test Lab (расчет прогиба балки, напряжения фон Мизеса, Shock Test).
* **`widget-ergonomics.html`** — Автономный виджет калькулятора эргономики ISO 9241-5 с интерактивными слайдерами роста и стола.
* **`tilda-global-enhancements.html`** — Сквозной скрипт: Командная палитра (`⌘K` / `Ctrl+K`) + тактильный Web Audio звук микро-кликов.
* **`test-stand.html`** — Интерактивный локальный стенд для проверки работы всех виджетов и корзины перед заливкой на Тильду.

## 🚀 Пошаговый план запуска на Тильде

### Шаг 1. Импорт каталога товаров в Tilda Store
1. Откройте панель управления вашим сайтом в Тильде.
2. В левом меню выберите раздел **«Товары»** (Tilda Store).
3. Нажмите в правом верхнем углу **«Импорт товаров»** -> **«Импорт из CSV»**.
4. Загрузите файл **`tilda-hybrid/tilda-catalog-import.csv`**.
5. Проверьте соответствие колонок (Тильда автоматически распознает `Title`, `Price`, `Category`, `Characteristics` и др.) и нажмите **«Импортировать»**.
6. *Результат:* Все подставки, кронштейны, аксессуары и коврики созданы в каталоге с правильными категориями и ценами.

---

### Шаг 2. Настройка корзины Тильды (`ST100`)
1. На вашей главной странице добавьте из библиотеки блок **«Магазин»** -> **«ST100 (Корзина с формой заказа)»**.
2. В настройках блока включите удобные поля (Имя, Телефон, Город, Адрес доставки).
3. В **Настройках сайта -> Платежные системы** подключите ваш эквайринг (ЮKassa, Т-Банк, Сбер или Долями) и службу доставки (СДЭК).
4. *Как это работает с конфигуратором:* Наш 3D-виджет Focus Station автоматически обращается к функции `window.tcart__addProduct(...)`. Когда клиент нажимает «Добавить в корзину» в конфигураторе, кастомная сборка (с учетом выбранной длины, дерева, гравировки и аксессуаров) сразу падает в эту корзину `ST100`.

---

### Шаг 3. Вставка интерактивных инженерных виджетов (Блок `T123`)

На странице сайта в местах, где должны располагаться конфигуратор и симуляторы, добавьте блоки **«Другое» -> «T123 (HTML-код)»**:

#### 1. 3D Конфигуратор Focus Station:
* Добавьте блок `T123`.
* Откройте контент блока и скопируйте туда весь код из файла **`tilda-hybrid/widget-3d-configurator.html`**.
* Сохраните.

#### 2. FEA Stress Test Lab (Сопромат):
* Добавьте следующий блок `T123`.
* Скопируйте туда содержимое файла **`tilda-hybrid/widget-fea-lab.html`**.
* Сохраните.

#### 3. Калькулятор эргономики ISO 9241-5:
* Добавьте блок `T123`.
* Скопируйте содержимое файла **`tilda-hybrid/widget-ergonomics.html`**.
* Сохраните.

---

### Шаг 4. Подключение глобальных улучшений (⌘K и Звук)
Чтобы на всем сайте работала палитра быстрого поиска по клавишам `⌘K` / `Ctrl+K` и тактильные микро-клики при нажатии на кнопки:
1. Перейдите в **«Настройки сайта»** -> вкладка **«Еще»** -> пункт **«HTML-код для вставки внутрь HEAD или BODY»**.
2. Либо добавьте блок `T123` в сквозной подвал сайта (**Footer**).
3. Вставьте содержимое файла **`tilda-hybrid/tilda-global-enhancements.html`**.

---

### Шаг 5. Рекомендуемая раскладка стандартных блоков Тильды для остальных секций

Для тех частей сайта, которые не требуют кастомного JS, лучше всего использовать проверенные блоки Тильды (их смогут легко редактировать маркетологи):

| Секция GEEK NOOK | Рекомендуемый блок Тильды | Примечание |
| :--- | :--- | :--- |
| **Главный экран (Hero)** | `CR30` или `Zero Block` | Заголовок «Инженерная точность», фоновое видео или фото |
| **Преимущества (6 колонок)** | `FR301` или `FR101` | Сталь, Дерево, Фетр, Точность, Надежность, Минимализм |
| **Каталог товаров** | `ST305N` или `ST310N` | Автоматически подтягивает товары из Tilda Store, импортированные на Шаге 1 |
| **Отзывы / Сетапы клиентов** | `SL02` (слайдер) или `GL08` | Фото реальных рабочих мест клиентов с цитатами |
| **Производство / Манифест** | `AB101` или `TX16N` | Фотографии фрезерного ЧПУ-цеха и манифест качества |
| **Статьи журнала** | Потоки Тильды (Feeds) / `FE101` | 3 статьи об эргономике и продуктивности стола |
| **Часто задаваемые вопросы (FAQ)** | `TX16N` (Аккордеон) | 6 ответов на популярные вопросы |
| **Запрос B2B КП** | `BF301` (Форма заявки) | Поля: Компания, Email, Количество мест (с интеграцией в Telegram/CRM) |
| **Контакты и Юр. инфо** | `FT101` / `FT201` | Ссылки на гарантию 2 года, оферту, Telegram |

## 🧪 Как протестировать прямо сейчас на компьютере

Для удобства мы создали файл **`tilda-hybrid/test-stand.html`**.
Вы можете открыть его в любом браузере:
* В нем полностью сымитирована работа Тильды: навигация, выезжающая корзина `ST100`, расчет цен, добавление конфигураций, переключение тем и физический расчет FEA.
