# GEEK NOOK — Инженерная точность на твоём столе

Премиальные модульные настольные органайзеры, флагманские подставки под мониторы **Focus Station**, кронштейны **T-Track** и аксессуары из натурального дерева, стали и фетра.

---

## 🛠 Технологический стек

* **Frontend Core:** Чистый Vanilla JavaScript (ES6+) без внешних фреймворков (zero-runtime overhead).
* **Стилизация:** Инженерная система дизайна на чистом CSS3 (CSS Custom Properties, Fluid Layout, Glassmorphism, Dark/Light Themes).
* **3D Движок:** [Three.js](https://threejs.org/) (процедурные шейдеры текстур дерева без тяжелых внешних карт нормалей).
* **Физический симулятор:** Canvas 2D сопромат-движок расчета упругих деформаций и напряжений (FEA Stress Test Lab).
* **Аудио:** Синтез тактильных микро-кликов через нативный Web Audio API (Micro-Haptics).

## ⚡ Ключевой функционал

1. **3D Конфигуратор Focus Station:**
   * Процедурная генерация текстур пород дерева: Тёмный дуб, Светлый дуб, Орех, Чёрный матовый.
   * Интерактивная смена длины основания (85 / 116 см) и выбор навесных T-Track модулей.
   * Лазерная гравировка в реальном времени.
   * Шеринг кастомной конфигурации по уникальной ссылке (`?cfg=...`).

2. **FEA Stress Test Lab (МКЭ/Сопромат):**
   * Расчет физического прогиба полки под нагрузкой от 5 до 50 кг по формуле Эйлера-Бернулли.
   * Тепловая карта распределения механических напряжений фон Мизеса на Canvas.
   * Тест на ударную вибрационную нагрузку (Shock Test).

3. **360° Stealth Cable Management:**
   * Интерактивная модель прокладки кабелей питания, мониторов и периферии.

4. **Калькулятор эргономики (ISO 9241-5):**
   * Расчет оптимальной высоты стола, кресла и верхней кромки экрана под рост пользователя.

5. **Spotlight / Command Palette (`⌘K` / `Ctrl+K`):**
   * Быстрый поиск по всем доскам и аксессуарам, переход к разделам, переключение темы.

6. **Web Audio API Micro-Haptics:**
   * Тактильная звуковая обратная связь при кликах и взаимодействиях (клавиша `S` для включения/выключения).

7. **Двусторонняя корзина и чекаут:**
   * Slide-over корзина с защитой от переполнения квоты (`safeStorage`).
   * Покупка в 1 клик и оформление заказа с автоматической генерацией заявки в Telegram.

## 🚀 Запуск и деплой

### Локальное тестирование
Вы можете открыть `index.html` напрямую в браузере или запустить локальный статический сервер:
```bash
# Через npx serve:
npx serve .

# Или через Python:
python -m http.server 8000
```

### Выкладка на продакшен-хостинг
1. Загрузите содержимое каталога на ваш веб-сервер по FTP / SFTP в корневую директорию сайта (обычно `public_html/` или `www/`).
2. Убедитесь, что веб-сервер Apache имеет включенные модули:
   * `mod_rewrite` (для редиректа на HTTPS)
   * `mod_deflate` (для сжатия трафика)
   * `mod_expires` (для кэширования статики)
   * `mod_headers` (для заголовков безопасности)
3. Файл `.htaccess` автоматически активирует все правила оптимизации и безопасности.
