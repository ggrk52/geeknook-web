## 📌 О проекте

Официальная веб-платформа российского бренда инженерных аксессуаров для организации рабочего пространства **GEEK NOOK**:
* Флагманские модульные подставки под мониторы **Focus Station** (массив американского ореха, кавказского дуба и черного ясеня на стальном шасси);
* Модульная система кронштейнов **T-Track** и навесных аксессуаров;
* Интерактивный 3D-конфигуратор рабочего места на базе Three.js;
* Научно-инженерный симулятор сопромата (FEA Stress Test Lab) для расчета деформаций и распределения напряжений по формуле Эйлера-Бернулли;
* Headless-интеграция с платежным шлюзом и доставкой СДЭК через нативный слой корзины.

---

## 🛠 Технологический стек

* **Frontend Core:** Нативный Vanilla JavaScript (ES6+) без внешних тяжелых фреймворков (нулевой оверхед, экстремальный FPS).
* **Стилизация:** Фирменная инженерная дизайн-система на чистом CSS3 (Custom Properties, Fluid Clamp Typography, Glassmorphism, адаптивность 320px–4K, темная/светлая темы).
* **3D Движок:** [Three.js](https://threejs.org/) — процедурная генерация текстур пород дерева и лазерной гравировки в реальном времени.
* **Физический симулятор:** HTML5 Canvas 2D сопромат-движок расчета упругих деформаций и механических напряжений фон Мизеса под нагрузкой 5–50 кг.
* **Аудио-движок:** Синтез тактильного звукового отклика через нативный Web Audio API (Micro-Haptics).
* **Интеграции:** Headless-мост Tilda CRM / ST100, онлайн-оплата (ЮKassa / Т-Банк / СБП), автоматический расчет и интерактивный выбор ПВЗ СДЭК на карте, B2B-калькулятор и Telegram Lead Bot.

## 🔒 Внутренняя разработка и CI/CD (Internal Only)

> [!NOTE]
> Данный раздел предназначен **исключительно для авторизованной команды инженеров и администраторов GEEK NOOK**.

### 1. Локальное окружение разработчика
Для локальной отладки компонентов и 3D-конфигуратора:
```bash
# Запуск локального тестового сервера (порт 8000)
python3 -m http.server 8000
```
После запуска открыть в браузере: `http://localhost:8000/`.

### 2. Сборка и минификация продакшен-бандлов
Перед отправкой изменений в основную ветку обязательно запускается пайплайн оптимизации:
```bash
# Минификация CSS и JS с сохранением строгой синтаксической валидности
python3 scripts/build-minified.py

# Сборка чистого резервного архива релиза
python3 scripts/build-archive.py
```

### 3. Регламент деплоя (Production Pipeline)
* Основная ветка `main` синхронизирована с CDN GitHub Pages (`ggrk52.github.io/geeknook-web/`).
* Боевой домен [geeknook.ru](https://geeknook.ru) под управлением CMS Tilda автоматически загружает актуальную сборку ядра через защищенный загрузчик `tilda-loader.html`.
* Приватные API-ключи Telegram и СДЭК изолированы на защищенном бэкенде и исключены из системы контроля версий.
