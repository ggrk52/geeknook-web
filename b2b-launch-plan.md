# План реализации B2B-направления GeekNook (`b2b-launch-plan.md`)

**Цель:** Развернуть корпоративное B2B-направление GeekNook с нуля: запустить отдельную конверсионную страницу `b2b.html`, настроить моментальный сбор лидов в Telegram, подготовить презентацию-КП (Pitch Deck) с оффером «Офисный тест-драйв на 14 дней», вооружить ментора Валеру инструментами для теплого нетворкинга и четко разграничить технические и операционные задачи.

## ЧАСТЬ I. Задачи в проекте (Техническая реализация)

### Фаза 1. Устранение блокеров и инфраструктура лидогенерации
* [ ] **1.1. Исправление обработчика B2B-формы в `js/modern-app.js`:**
  * Найти функцию `handleB2bSubmit` (строки 7707–7720).
  * Устранить баг потери лидов: сейчас вызывается только аналитическая цель Метрики `trackB2bLead`.
  * Реализовать отправку данных (Компания, ИНН, Контактное лицо, Телефон, Email, Количество мест, Выбранный пакет) через защищенный шлюз в Telegram Bot API.
  * Добавить визуальный feedback: спиннер отправки, экран успешной заявки с подтверждением «Наш инженер свяжется с вами в течение 10 минут».
* [ ] **1.2. Создание серверного/безопасного обработчика лидов:**
  * Создать легковесный эндпоинт `api/b2b-lead.php` для безопасной отправки в Telegram без раскрытия токена бота в клиентском JavaScript (с fallback на клиентский запрос при статическом хостинге).
* [ ] **1.3. Юридическая и налоговая синхронизация (НДС):**
  * В `index.html` (строка 2702) убрать дезинформирующую формулировку *«с НДС 20%»*.
  * Внедрить юридически выверенный стандарт: *«Оплата по безналичному расчету (УПД без НДС для УСН / поставка с НДС 20% через аккредитованного партнера)»*.

### Фаза 2. Разработка автономной посадочной страницы `b2b.html`
* [ ] **2.1. Каркас и метаданные:**
  * Создать файл `b2b.html` в корне проекта с чистым URL (доступен по адресу `/b2b`).
  * Настроить Open Graph теги для шеринга в Telegram/VK (превью-картинка B2B-сетапа, заголовок: *«GeekNook B2B // Эргономичные рабочие пространства для IT-команд»*).
  * Обеспечить строгое соблюдение правил: нулевой горизонтальный скролл на 320px+, поддержка светлой и темной тем, touch-мишени от 44px.
* [ ] **2.2. Блочная структура страницы `b2b.html`:**
  * **Hero-экран:** Заголовок *«Инженерные рабочие места, в которые разработчики захотят возвращаться»*. Визуальный фокус на эстетике массива дуба, стали и T-Track. CTA-кнопка: *«Заказать бесплатный тест-драйв в офис»*.
  * **Блок болей RTO & Health:** Статистика утомляемости инженеров, синдром «текстовой шеи», сертификация эргономики ISO 9241-5, стандартизация кабель-менеджмента (пожарная безопасность офиса).
  * **Лид-магнит №1: «Офисный тест-драйв на 14 дней»:** Подробный блок механики (доставляем 1 сетап Focus Station в ваш офис, тестируете на тимлиде 2 недели бесплатно).
  * **Интерактивный B2B-конфигуратор пакетов:**
    * *Startup Pack (5–10 мест):* Focus Station 85 + держатели ноутбуков (скидка 10%).
    * *Growth Team (11–25 мест):* Focus Station + ноутбук + наушники (скидка 15%).
    * *Enterprise Pro (26–50+ мест):* Полный сетап Focus Station 116 орех + кожаный коврик XL + кабель-трей (скидка 20%).
    * *Custom Project:* Индивидуальная интеграция под проект архитектора.
  * **Корпоративная кастомизация:** Лазерная гравировка логотипа компании на металлическом шильдике, блинтовое тиснение на ковриках, подбор оттенка древесины под брендбук.
  * **Секция для архитекторов и дизайнеров интерьеров:** Форма запроса 3D CAD-библиотеки (.STEP, .3DS, .DWG) с агентской программой комплектации (10% cashback).
  * **Форма мгновенного расчета и заказа тест-драйва:** Простая и удобная форма с валидацией ИНН компании через подсказки Дадата/валидатор.

## ЧАСТЬ II. Что нужно сделать НА СТОРОНЕ (Зона ответственности команды и фаундера)

Этот блок задач невозможно выполнить через программный код. Это физические и коммуникационные действия:

### 1. Коммуникация с ментором Валерием (Сегодня)
* [ ] **1.1. Отправить Валере согласованный ответ** (по шаблону из предыдущего шага), поблагодарить за импульс и объяснить фокус на теплом нетворке и тест-драйвах.
* [ ] **1.2. Передать Валере «Forwardable Message Kit»** вместе со сгенерированным PDF-файлом презентации.
* [ ] **1.3. Попросить Валеру переслать питч 3–5 знакомым фаундерам/топам** в IT-сфере с вопросом: *«Хотите поставить один тестовый сетап себе в офис бесплатно на 2 недели?»*.

### 2. Техническая настройка Telegram-бота для лидов (15 минут)
* [ ] **2.1. Открыть `@BotFather` в Telegram:**
  * Создать нового бота (команда `/newbot`), например: `GeekNookLeadsBot`.
  * Скопировать полученный `API TOKEN`.
* [ ] **2.2. Создать закрытую группу Telegram для команды GeekNook:**
  * Добавить созданного бота в группу.
  * Узнать `chat_id` группы (через `@getmyid_bot` или API).
  * Передать `TOKEN` и `chat_id` для внесения в файл конфигурации скрипта отправки лидов.

### 3. Производство и сборка 2 комплектов «Demo Box» (Дни 2–4)
* [ ] **3.1. Выделить из мастерской 2 образцовых комплекта Focus Station 85:**
  * Один комплект из массива кавказского дуба (натуральный/темный).
  * Один комплект из американского ореха.
  * Укомплектовать держателем для ноутбука, подвесом для наушников, кабельным лотком и ковриком.
* [ ] **3.2. Подготовить транспортировочные кофры/коробки:**
  * Сетап должен приезжать в офис клиента не в технической стрейч-пленке, а в презентабельной, чистой упаковке с фирменной наклейкой GeekNook.
  * Вложить внутрь ламинированную инструкцию по быстрой настройке за 3 минуты и открытку с контактами персонального менеджера.

### 4. Производственная инвентаризация и неснижаемый буфер (Дни 3–5)
* [ ] **4.1. Провести ревизию сырья в цеху:**
  * Зафиксировать физический остаток сухого дуба и ореха.
  * Обеспечить запас заготовок древесины и нарезанного T-Track профиля минимум на **15 рабочих мест**.
  * Это предотвратит «эффект KUB», когда поступает оптовый заказ, а мастерская физически не может его отгрузить из-за нехватки сырья.

### 5. Налоговая и бухгалтерская подстраховка по НДС 20% (Дни 5–7)
* [ ] **5.1. Найти дружественную компанию на ОСНО:**
  * Среди знакомых поставщиков мебели, офисного оборудования или IT-интеграторов согласовать агентскую схему: в случае крупного корпоративного тендера с требованием НДС 20% провести поставку через них с выплатой агентской комиссии 5–7%.

### 6. Полевой тест-драйв и фотоконтент (Дни 7–14)
* [ ] **6.1. Доставить первые комплекты по договоренностям Валеры:**
  * Привезти сетап в офис, помочь аккуратно установить на рабочий стол лид-разработчика или фаундера.
* [ ] **6.2. Провести интерьерную фотосъемку:**
  * С разрешения клиента сделать 5–10 качественных фото сетапа в реальном опенспейсе IT-компании.
  * Эти фото станут главным социальным доказательством для страницы `b2b.html` и будущих коммерческих предложений.
